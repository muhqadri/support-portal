## Git questions

**1. What does `git clone` do?*

It creates a local copy of a remote repository, including its files and Git history.

**2. What is the difference between `git commit` and `git push`?**

A commit saves changes to the local Git history. A push sends local commits to the remote repository on GitHub.

**3. Why did we run `git pull` after editing the README on GitHub?**

The README was changed on GitHub, so we pulled the update to bring the remote commit into our local repository.

**4. What does `origin` mean?**

`origin` is the default name for the remote repository that the local repository connects to, usually the GitHub repository we cloned.
